# Inception — A Mind-Bending Thriller

## Overview
**Title:** *Inception*  
**Director:** **Christopher Nolan**  
**Release Year:** **2010**

> "An idea is like a virus. Resilient. Highly contagious."  
> — *Inception* (captures the film's central theme about ideas and reality)

### Key Features
1. Multi-layered dream-within-a-dream structure  
2. Strong emotional core (Cobb's family and guilt)  
3. Visually inventive set pieces and practical effects

---

### Main Characters
- **Dom Cobb** — Protagonist, extractor  
- **Ariadne** — Architect (designs the dream levels)  
- **Arthur** — Point man, Cobb's right-hand  
- **Mal** — Cobb's late wife, haunting presence

### Short Plot (step-by-step)
1. Cobb is hired to *implant* an idea (inception) rather than steal one.  
2. The team assembles: architect, forger, chemist, and point man.  
3. They build layered dreams to reach the target's subconscious.  
4. Emotional stakes rise as Cobb's past (Mal) sabotages the mission.

---

**Runtime:** *148 minutes*  
**Genre:** *Science fiction / Thriller*
